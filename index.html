Before You Begin

Welcome to the APA Reference Builder Lab

This activity is designed to help you learn how APA reference entries are built and how to use APA Style as a problem-solving resource. Instead of memorizing rules in the abstract, you will identify source details, build references, verify your decisions, and document completion.

What you are learning

  • Identify source information: locate the author, date, title, source, and DOI or URL.
  • Build an APA reference: assemble those elements into the correct APA sequence.
  • Use APA Style strategically: choose the right category and example when a source is unfamiliar.
  • Track completion: finish all source types and unlock a named badge and completion code.

Why this matters

Reference pages are not just about following rules. They make research traceable and show readers where evidence comes from.

This lab also teaches you how to use an authoritative resource when you are unsure, which is a more durable skill than memorizing isolated examples.

The goal is not perfection on the first try. The goal is to build a repeatable process for recognizing source types, checking conventions, and revising with confidence.

How the lab works

  1. Enter your name so the completion badge can be personalized.
  2. Use the APA Navigation Lab to practice finding the right example.
  3. Choose a source type and inspect the source snapshot.
  4. Build the reference and check the diagnostic feedback.
  5. Verify your work against the APA model.
  6. Mark each source complete and unlock the final badge.

Student badge setup

You can explore the lab without entering a name, but a name is required before the completion badge can be unlocked.
