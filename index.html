Before You Begin

Welcome to the APA Reference Builder Lab

This activity helps students learn how APA reference entries are built and how to use APA Style as a problem-solving resource. Instead of memorizing rules in the abstract, students identify source details, build references, verify decisions, and document completion.

What students are learning

  • Identify source information: author, date, title, source, DOI, or URL.
  • Build an APA reference: place those elements in the correct sequence.
  • Use APA Style strategically: find the correct category and example when a source is unfamiliar.
  • Track completion: finish all practice sources and unlock a named badge and completion code.

Why this matters

Reference pages make research traceable and show readers where evidence comes from.

This lab teaches students how to use an authoritative resource when they are unsure, which is more durable than memorizing isolated examples.

The goal is a repeatable process for recognizing source types, checking conventions, and revising with confidence.

How the lab works

  1. Enter your name so the completion badge can be personalized.
  2. Choose a source type and inspect the source snapshot.
  3. Build the reference and check the diagnostic feedback.
  4. Use the APA Navigation Lab before verifying the source against an APA Style example.
  5. Mark each source complete after successful checking and guide completion.
  6. Unlock the final badge after all source types are complete.
